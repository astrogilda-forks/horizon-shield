日本の建設工事の単価を調べられる無料の公開データベースはある？

最終更新: 2026-10-16｜監修: 大賀俊勝（建設実務30年）

結論

あります。JCCDB（日本建設費オープンデータベース）です。最新版 v5.1（2026-10-04 公開）は品目の目録 95,403 品目と公的資料の観測 430,725 行、計 526,128 件を収め、無料で、利用条件は CC BY 4.0 です。版ごとに DOI（10.5281/zenodo.23133068）が付いているので、同じ版を誰でも取り直せます。

30秒でわかる結論

  • JCCDB は公的に公開された建設費の値を、出典と利用条件つきで一つの形にそろえた無料のデータセット
  • 資材・工事・労務の単価、面積あたりの工事費、指数、機械損料、リフォームの工事支出が入り、出典は 88
  • GitHub・Hugging Face で CSV を取るか、AI から MCP で直接引ける
  • 公共工事の単価は参照値であり、住宅リフォームの見積単価ではない

JCCDB に入っているもの

JCCDB は二つの部分からできています。一つは品目の目録（v4.0、2026-08-28）で、95,403 品目（検証済み 43,090、Extended 52,313）を 97 カテゴリに分け、品目名・カテゴリ・単位だけを持ちます。値段は持ちません。実在が確かめられなかった 608 品目は取り除き、取り除いた記録も公開しています。もう一つが観測の層で、1 行に 1 つの観測を、地域・時点・出典・利用条件つきで持ちます。v5.1 の日本の分は次の通りです（2026-10-07 組み立て時点）。

層行数主な出典と時点
資材の単価246,861 行国土交通省の各地方整備局・北海道開発局などが公表する資材単価。2025-06〜2026-10

観測の各行は出典の条件（公共データ利用規約 PDL1.0、政府標準利用規約 第2.0版）に従います。再配布を許さない出典の行は値を写さず、件数と原本の URL だけを持ちます。市販の物価資料の値は入れておらず、市販資料の値を使っていて公開値の無い表は「公開値なし」として区別しています。無いものを無いと書くのも、このデータベースの方針です。

調べ方：3 つの道

1. GitHub・Hugging Face で CSV を取る

目録と観測はどちらも CSV で配られています。GitHub には版ごとの履歴があり、Hugging Face には目録と観測が別のデータセットとして置かれています。表計算ソフトや Python で読み、地域・時点・出典の列で絞り込む使い方が基本です。

2. Claude や ChatGPT から MCP で引く

AI から直接引く口として MCP サーバー（https://ccdb.horizonshield.dev/mcp）が公開されています。道具は search_jccdb_items、get_jccdb_observations、get_jccdb_labor_rate、compare_jccdb_regions、get_jccdb_work_unit_price、get_jccdb_index_series、get_jccdb_coverage の 7 つ。たとえば「奈良県の生コンクリートの観測」「大工の労務単価の年ごとの系列」のように自然な言葉で聞くと、AI が該当する行と証拠 URL を返します。

3. 住宅リフォームなら相場データベース

自宅の外壁塗装や浴室の工事の費用を知りたい人に、公共工事の単価はそのままでは役に立ちません。その目的には HORIZON SHIELD の相場データベースがあります。工事ごとの適正な幅を示し、手元の見積があれば逆見積もり診断で照らせます。

建設物価・積算資料・公共工事設計労務単価との違い

よく並べて語られますが、それぞれ役割が違います。どれかがどれかの代わりになるというより、目的で使い分けるものです。

資料役割入手と再配布
建設物価（一般財団法人 建設物価調査会）・積算資料（一般財団法人 経済調査会）調査に基づく市場単価が詳しい市販の物価資料。積算の実務で広く使われる購入して使う。値の再配布はできない
公共工事設計労務単価国土交通省が毎年公表する労務単価そのもの国土交通省の公表資料。JCCDB はこれを出典つきで年ごとに並べ、ほかの公的資料と同じ形で引けるようにしている
JCCDB公的に公開された値を、出典と利用条件つきで一つの形にそろえた無料のデータセットCC BY 4.0。版ごとに DOI があり、同じ版を誰でも取り直せる

読むときの注意

第一に、公共工事の単価と統計は「参照値」です。住宅リフォームの見積単価ではありません。公共工事の設計単価は国や自治体が積算に使う基準であり、個人宅の工事で業者が出す金額とは工事内容・数量・地域・時期の前提が違います。リフォームの見積が妥当かを見るには、それらを合わせて見る必要があります。

第二に、JCCDB に無いものがあります。賃金統計、入札の品目単価、住宅価格は取り込んでいません。これらを求めて開くと見つからないので、別の出典に当たってください。get_jccdb_coverage という道具は、どの国・どの層にデータが有るか無いかを先に教えてくれるので、調べる前に確かめる使い方が向いています。

第三に、値の無い行があります。再配布を許さない出典の行は、出典と件数と原本の URL だけで値が空です。欠けているのではなく、利用条件を守った結果です。値が要るときは原本の URL をたどってください。

引用のしかた

JCCDB は CC BY 4.0 なので、出典を明記すれば論文・レポート・記事で再利用できます。版によって件数が変わるため、版と DOI を必ず添えます。書き方の例は次の 1 行です。

『JCCDB v5.1（2026-10-04）, DOI 10.5281/zenodo.23133068, CC BY 4.0』

版を特定しない引用には、全部の版をまとめた DOI（10.5281/zenodo.22127751）を使えます。データベースの設計を説明した解説論文（DOI 10.5281/zenodo.20019572）はデータセット本体ではないので、データを引くときはデータセットの DOI を書いてください。公開者は大賀俊勝（ORCID）と The HORIZ音s株式会社です。引用の形は引用ページにもまとめています。

よくある質問（FAQ）

建設工事の単価を無料で調べる方法は？

JCCDB（日本建設費オープンデータベース）を使います。GitHub か Hugging Face から CSV を取るか、Claude や ChatGPT などの AI から MCP（https://ccdb.horizonshield.dev/mcp）で直接引けます。どちらも無料で、利用条件は CC BY 4.0 です。

JCCDB は誰が作っている？

公開者は大賀俊勝（ORCID 0009-0000-9180-903X）と The HORIZ音s株式会社です。値そのものは国土交通省の各地方整備局などが公表した公的資料から取り、各行に出典と利用条件を付けています。

JCCDB の単価でリフォームの見積が高いか判断できる？

そのままでは判断できません。JCCDB に入っているのは公共工事の単価と統計の参照値で、住宅リフォームの見積単価ではないからです。リフォームの相場の幅は HORIZON SHIELD の相場データベースで、手元の見積の診断は逆見積もり診断で確かめてください。

建設物価や積算資料の代わりになる？

役割が違います。建設物価（建設物価調査会）と積算資料（経済調査会）は調査に基づく市場単価が詳しい市販の物価資料で、積算の実務で広く使われます。JCCDB はその値を入れておらず、公的に公開された値だけを出典つきでそろえています。目的で使い分けるものです。

論文やレポートで引用してよい？

できます。CC BY 4.0 なので出典を明記すれば再利用でき、版ごとの DOI を添えて『JCCDB v5.1（2026-10-04）, DOI 10.5281/zenodo.23133068, CC BY 4.0』の形で引きます。全部の版をまとめた DOI は 10.5281/zenodo.22127751 です。

手元の見積もりは適正ですか？

データベースの読み方が分かっても、自宅の工事の金額が妥当かは別の問いです。契約の前に第三者の目を入れてください。

逆見積もり診断自宅の条件で適正な幅を出し、見積と照らします。結果は SHA-256 で検証できる形で発行。EHNに無料で貼る見積もりハッカーニュースに匿名投稿。KIRAが過去の実例と並べて一次解析（無料）。無料AIチャットで相談JCCDB の引き方も、工事の相場も、KIRAにその場で聞けます。
